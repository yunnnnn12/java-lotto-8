# java-lotto-precourse

## 1. 중요 키워드
- **구입 금액 입력**: 1000원 단위, 나누어 떨어지지 않으면 예외 처리
- **구매 목록**: 입력 금액에 따라 랜덤 로또 생성
- **당첨 번호 입력**: 중복 없는 숫자 6개
- **보너스 번호 입력**: 당첨 번호와 중복 X
- **당첨 통계 출력**: 각 로또와 당첨 번호 비교, 결과 출력
- **수익률 출력**: 전체 당첨금 대비 투자 금액

---

## 2. 구현 기능 큰 단위로 나누기

### 1) 입력(Input)
#### a. 구입 금액 입력
- 1000원 단위로 입력 받아야 함
- 숫자 외 입력 시 예외 발생
- 1000원 단위가 아닐 경우 예외 발생

#### b. 당첨 번호 입력
- 1~45 범위 숫자 6개
- 쉼표로 구분
- 중복된 숫자가 있으면 예외 발생
- 숫자 외 입력 시 예외 발생

#### c. 보너스 번호 입력
- 1~45 범위 숫자 1개
- 당첨 번호와 중복되면 예외 발생
- 숫자 외 입력 시 예외 발생

---

### 2) 로또(Lotto) 모델
- **Lotto 객체**
    - 6개의 번호를 가진 리스트
    - 번호 중복 X, 1~45 범위
    - 생성 시 정렬 수행
- **Lottos 컬렉션**
    - 구입 금액에 따라 생성된 여러 Lotto 객체를 담음
- **Rank(Enum)**
    - 당첨 결과 구분 (1등~5등, 미당첨)
    - `matchCount`, `bonusMatch`, `prize` 속성
    - `matchCount`와 `bonusMatch`로 Rank 계산

---

### 3) 서비스(Service)
- **LottoService**
    - 랜덤 로또 생성: 구입 금액에 맞춰 로또 줄 생성
    - 당첨 번호 비교: 각 로또와 당첨 번호, 보너스 번호 비교
    - 수익률 계산: 총 당첨금 / 구입금 * 100

---

### 4) 출력(Output)
- **OutputView**
    - 구매한 로또 번호 출력
    - 당첨 통계 출력
    - 수익률 출력

---

### 5) 컨트롤러(Controller)
- **LottoController**
    - InputView로부터 입력 받기
    - LottoService로 로또 생성, 비교, 수익률 계산
    - OutputView로 결과 출력
    - 입력 예외 처리 포함

---

## 3. 구현 흐름

1. 사용자로부터 **구입 금액** 입력
    - 입력 검증 → 예외 처리

2. **로또 생성**
    - `구입금액 / 1000`만큼 로또 줄 생성
    - 각 줄 6개 랜덤 번호 생성(1~45)

3. 사용자로부터 **당첨 번호 입력**
    - 쉼표로 6개 입력
    - 중복, 범위, 숫자 검증

4. **보너스 번호 입력**
    - 1개 입력
    - 당첨 번호와 중복 검증, 범위 검증

5. **당첨 비교**
    - 각 로또 줄과 당첨 번호 비교
    - Rank 계산

6. **결과 출력**
    - 각 로또 줄 출력
    - 당첨 통계 출력
    - 수익률 출력

---

## 4. 테스트 전략

### 1) 단위 테스트
- **Lotto 클래스**
    - 6개 번호 미만/초과 → 예외
    - 중복 번호 → 예외
    - 정상 번호 → 정상 생성
- **Rank**
    - `matchCount` + `bonusMatch`에 따른 Rank 값 확인
- **LottoService**
    - 랜덤 로또 생성 개수 검증
    - 당첨 비교 로직 검증
    - 수익률 계산 검증

### 2) 통합/시나리오 테스트
- 구입 금액 입력 → 로또 생성 → 당첨 번호 입력 → 보너스 번호 입력 → 최종 결과 출력
- 잘못된 입력에 대한 예외 처리 확인

---

## 5. 개발 순서 제안

1. **모델 작성**
    - Lotto, Lottos, Rank 클래스
    - 단위 테스트 작성 및 검증

2. **서비스 작성**
    - LottoService (로또 생성, 당첨 비교, 수익률 계산)
    - 서비스 단위 테스트 작성

3. **입력/출력 뷰 작성**
    - InputView: 구입금액, 당첨번호, 보너스번호 입력
    - OutputView: 로또 목록, 당첨 통계, 수익률 출력

4. **컨트롤러 작성**
    - InputView → LottoService → OutputView 흐름
    - 예외 처리 포함

5. **통합 테스트 작성**
    - ApplicationTest 작성
    - 시나리오 기반 기능 테스트
    - 잘못된 입력 예외 테스트
